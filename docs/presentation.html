Introduction

What is SmartHire?

SmartHire is a full-stack recruitment SaaS platform engineered to resolve the massive information asymmetry between job seekers and hiring managers.

1. Job Seekers / Candidates

Build verified profiles, upload resumes for automated parsing, explore personalized job recommendations, and review itemized skill gaps before applying.

2. Employers / Recruiters

Post job openings with custom skill importance weights, review candidates ranked automatically by match %, inspect resumes, and manage interview pipelines.

3. System Administrators

Oversee platform demographics, monitor real-time application funnels, moderate job vacancies, and manage user suspensions.

Industry Challenge

The Problem in Modern Recruitment

Candidate Pain Points:

  • The "Application Black Hole": Submitting hundreds of resumes with zero feedback on disqualifications.
  • Hidden Disqualifiers: No clear insight into whether education or experience deficits caused rejections.
  • Missing Skill Ignorance: Inability to identify which specific technical tools are required to close skill gaps.

Recruiter Bottlenecks:

  • Resume Overload: Open positions receive 500+ resumes, overwhelming manual screening capacity.
  • Unranked Inflow: Applications arrive chronologically rather than sorted by true qualification.
  • Duplicate Application Spam: Candidates repeatedly submit identical applications, corrupting pipeline metrics.

System Architecture

Three-Tier Decoupled Architecture

1. Client Tier (Frontend)

React 18 + Vite + Tailwind

Single Page Application with React Router v6. Utilizes Axios with JWT request/response interceptors, AuthContext, NotificationContext, and Recharts.

2. Application Tier (Backend)

Node.js + Express.js API

RESTful API with Helmet security headers, CORS protection, express-rate-limit, Multer resume uploads, and the core 5-factor recommendation engine.

3. Data Tier (Database)

MongoDB & Mongoose ODM

9 collections with indexing, compound unique constraints, and zero-config in-memory fallback server (`mongodb-memory-server`) for offline evaluation.

Core Technical Differentiator

5-Factor Explainable Recommendation Model

Overall Score = (Skills × 50%) + (Education × 15%) + (Experience × 15%) + (Preferences × 10%) + (Location × 10%)

Skills (50%)

Ratio of matched required skill weights to total required weights.

Education (15%)

Ordinal hierarchy: PhD (5) > Masters (4) > Bachelors (3) > Diploma (2).

Experience (15%)

Candidate years vs required years. Freshers scored 100% on entry roles.

Preferences (10%)

Alignment with preferred job types (full-time, internship) and roles.

Location (10%)

100% for remote; proximity checks against preferred candidate cities.

Resume Intelligence

Automated Resume Parser & Taxonomy

The Extraction Pipeline:

1. Ingestion of PDF or DOCX file up to 10MB using Multer.

2. Binary buffer decoded into textual stream via pdf-parse.

3. Regex token boundary scanning across our 200+ controlled technical skill taxonomy.

4. Automated extraction of contact details, education degrees, and estimated experience years.

Candidate Agency & Verification:

Extracted skills are displayed on an interactive dashboard. Candidates can add missed tools, remove errors, and adjust proficiency levels (Beginner, Intermediate, Advanced, Expert) with 1 click.

Recruiter Portal

Recruiter Pipeline & Candidate Ranking

1. Vacancy Posting with Weights

Recruiters post positions defining required skills and weighting their priority (1x Normal, 2x High, 3x Critical) to fine-tune matching.

2. Algorithmic Candidate Ranking

Applicants arrive pre-ranked by compatibility score (0–100%). Recruiters view matched skills and download authorized resumes.

3. Status Updates with Feedback

Shortlist, invite for interview, or reject with custom feedback notes, which automatically trigger candidate notifications.

Security & Compliance

Enterprise-Grade Security Architecture

Password Salting & Hashing

Passwords encrypted via bcryptjs (10 salt rounds). select: false prevents leakages in queries.

Role-Based Authorization

Server-side middleware validates JWT signature and checks req.user.role on every protected endpoint.

Authorized Resume Access

Resumes are never public. Access is restricted to the candidate, authorized recruiters, or admins.

Rate Limiting & Helmet Headers

Express rate limiters protect auth endpoints from brute force; Helmet sets secure HTTP security headers.

Database Modeling

Mongoose Schemas & Deduplication

User & Profile Schemas

Decoupled User (credentials, roles, suspension) and CandidateProfile (education, experience, skills).

Application Deduplication

Enforces { job: 1, candidate: 1 } unique compound index, rejecting duplicate submissions at DB level.

Zero-Config Memory Server

Embedded in-memory server fallback ensures instant execution on any system without pre-installed MongoDB.
